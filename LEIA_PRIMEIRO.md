# Como usar esta entrega

1. Extraia o ZIP em uma nova pasta, mantendo C:\dev\autoboost como backup.
2. Abra no VS Code a pasta com pubspec.yaml.
3. Execute flutter pub get e flutter analyze.
4. Leia README.md e docs/DOCUMENTACAO.md.
5. Siga docs/GITHUB.md para publicar; ainda não foi publicado.

Os três arquivos em lib receberam comentários explicativos. Não houve mudança no código executável Dart. O APK e os cadastros do celular não fazem parte deste ZIP. Não é preciso reinstalar o aplicativo apenas para acrescentar comentários.

O pacote exclui caches de compilação, arquivos .bak, configuração local do Android SDK e arquivos de IDE. O teste padrão do contador não foi incluído, pois já tinha sido desativado no projeto recebido.
